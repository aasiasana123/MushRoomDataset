In this exercise, you are required to build, train, evaluate, and compare CNN and RNN models for 
classification using the Mushroom/Fungi Classification (mashroom.csv) dataset. The dataset contains 
categorical information about different characteristics of mushrooms, such as cap shape, cap surface, odor, 
gill characteristics, stalk characteristics, habitat, and other features, along with a target class indicating the 
mushroom category.  
You will load and explore the dataset, preprocess the categorical features by converting them into a 
suitable numerical format, and prepare the data for Deep Learning. You will then design and implement CNN 
and RNN models using TensorFlow/Keras, train them using the specified batch sizes, epochs, and 
optimizers, and generate predictions on the test data. You will evaluate and compare both models using 
accuracy, confusion matrices, classification reports, and suitable visualizations. 
In the second part of the exercise, you will work with Generative AI and Natural Language 
Processing (NLP) by using the provided exercise_text.json file and the Hugging Face Transformers 
tokenizer to tokenize text data.
